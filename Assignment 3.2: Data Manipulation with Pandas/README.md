# Assignment 3.2: Data Manipulation with Pandas

## Overview
This assignment focuses on practicing data manipulation techniques using Python's Pandas library.

## Topics Covered
- Pandas Series and DataFrames
- DataFrame creation and manipulation
- Data selection and filtering
- Indexing using `loc` and `iloc`
- GroupBy and aggregation
- Merging and joining DataFrames
- Time Series data manipulation
- Rolling window operations

## Learning Outcomes
Through this assignment, I practiced working with structured datasets and learned how to manipulate, filter, analyze, and summarize data using Pandas.

**Tools & Technologies:** Python, Pandas, Jupyter Notebook, Google Colab
